# کیت شروع پروژه با Claude Code

این پوشه را ریشهٔ پروژه قرار دهید. Claude Code همه‌چیز را از همین فایل‌ها می‌خواند.

فایل‌های فنی عمداً انگلیسی‌اند، به دو دلیل: Claude Code با آن‌ها دقیق‌تر کار می‌کند و متن فارسی چند برابر توکن مصرف می‌کند. CLAUDE.md هم در هر پیام دوباره خوانده می‌شود. متن‌های رابط کاربری فارسی‌اند.

## محتوای کیت

| فایل | کاربرد |
| --- | --- |
| `CLAUDE.md` | حافظهٔ دائمی پروژه: استک، دستورها و قواعد. در هر جلسه خودکار خوانده می‌شود |
| `docs/PRD.md` | سند نیازمندی محصول فاز 1، شامل صفحات و معیار پذیرش هر صفحه |
| `docs/TASKS.md` | 11 مرحلهٔ ساخت (M0 تا M10)، با مدل و Effort پیشنهادی برای هر مرحله |
| `docs/ANALYSIS_SPEC.md` | نقاط چهره، فرمول‌ها و محدوده‌های مرجع |
| `docs/TREATMENTS.md` | پایگاه دانش درمان، قواعد ترتیب جلسات و منع مصرف |
| `docs/SAFETY.md` | قواعد ایمنی بالینی، حریم خصوصی و واژه‌گزینی |
| `docs/BRAND.md` | برند اپ، برند کلینیک و پزشک روی گزارش (white-label)، رنگ‌ها، فونت و لحن |
| `docs/design/screens/` | 7 طرح صفحه (مرجع بصری) |
| `prompts/01-KICKOFF.md` | سوپرپرامپت جلسهٔ اول |
| `prompts/02-EACH-SESSION.md` | پرامپت‌های آماده برای جلسات بعد |
| `.claude/skills/next-milestone/` | دستور `/next-milestone M1`: برنامه‌ریزی، ساخت و تست یک مرحله |

| `content/` | محتوای بالینی که فقط پزشک ارشد می‌نویسد، مثل پروتکل اورژانس |

## مراحل اجرا

1. Node.js نسخهٔ 20 یا بالاتر و Git را نصب کنید.
2. در VS Code افزونهٔ رسمی **Claude Code** را نصب کنید و با حساب Claude (Pro یا Max) وارد شوید.
3. این پوشه را در VS Code باز کنید. در ترمینال `git init` بزنید و یک commit اولیه بگیرید.
4. چند عکس آزمایشی از خودتان یا افراد بزرگسالِ راضی در پوشهٔ `test-assets/` بگذارید. این پوشه در Git ثبت نمی‌شود. از عکس بیمار واقعی تا پایان M9 استفاده نکنید.
5. پنل Claude Code را باز کنید و تنظیمات را بگذارید:
    - مدل: روی نام مدل پایین کادر پیام کلیک کنید و `opusplan` را بزنید، یا `/model opusplan` را تایپ کنید.
    - Effort: در همان پنجره، ردیف Effort را روی `high` بگذارید.
    - حالت: Plan را از نشانگر حالت انتخاب کنید، یا `/plan` را تایپ کنید.
6. متن `prompts/01-KICKOFF.md` را بفرستید، به سؤال‌ها جواب دهید و برنامهٔ M0 را تأیید کنید.
7. برای هر مرحلهٔ بعد، این دو کار را تکرار کنید:
    - `/clear` بزنید.
    - مدل و Effort همان مرحله را از `docs/TASKS.md` تنظیم کنید و `/next-milestone M1` (و M2 و ...) را بزنید.
8. اپ را روی گوشی تست کنید:
    - `npm run dev:https` را اجرا کنید و آدرس نمایش‌داده‌شده را روی گوشیِ متصل به همان Wi-Fi باز کنید.
    - دوربین فقط روی HTTPS کار می‌کند.
