# تناسب — آنالیز زیبایی‌شناسی چهره و برنامه‌ریزی درمان

اپ وب موبایل‌محور (PWA) با تم مشکی-طلایی برای پزشکان زیبایی، همراه با «اپ مراجع» برای بیماران.
همهٔ پردازش‌ها، شامل تشخیص نقاط چهره، آنالیز و شبیه‌سازی، **روی همان دستگاه** انجام می‌شود و عکس به هیچ سروری ارسال نمی‌شود.

> ابزار کمک‌تصمیم برای پزشک مجاز است و تشخیص نمی‌دهد. اعداد بالینی (حجم، واحد، محدودهٔ مرجع) تا بازبینی پزشک ارشد با `TODO(clinical)` مشخص شده‌اند.

## امکانات

| بخش | توضیح |
| --- | --- |
| پروندهٔ بیمار | کد یکتای بیمار (`TN-XXXX-XXXX-X`) برای بازیابی در مراجعات بعدی، جستجو با نام، شمارهٔ پرونده یا کد |
| شرح حال و رضایت | سؤال‌های ایمنی، منع مصرف‌ها، فیتزپاتریک و گلوگو، رضایت‌های جداگانه، غربالگری BDD (فقط برای پزشک)، توقف برای سن زیر ۱۸ |
| عکس‌برداری | تعداد و نوع عکس لازم بر اساس **خدمت** (لب، زیر چشم، بوتاکس، گونه/نخ، فک و چانه، گردن، پوست، آنالیز کامل). بخش جداگانهٔ **قبل** و **بعد**، **راهنمای تصویری و متنی کنار هر عکس**، **تأیید فوری** هر عکس با بررسی خودکار کیفیت (زاویهٔ سر، اندازه، نور، وضوح، نور پشت سر) و گزینه‌های پذیرش، استفاده با وجود ایراد یا گرفتن دوباره. عکس «قبل» به‌صورت شفاف روی دوربینِ عکس «بعد» نمایش داده می‌شود |
| آنالیز | ۴۷۸ نقطهٔ چهره (MediaPipe)، یک‌سوم‌ها و پنج‌قسمتی، شیب چشم، نسبت لب‌ها، عرض بینی و دهان، شکل صورت، قرینگی نواحی و کالیبراسیون میلی‌متری با قطر عنبیه. نقشهٔ حرارتی نواحی قابل بهبود؛ درجه‌بندی ۰ تا ۴ در حجم و پیری، حرکت، لب و پوست؛ پزشک هر یافته را تأیید، ویرایش یا رد می‌کند |
| سن | دکمه‌های گروه سنی، سن واقعی و ظاهری، اسلایدر سن هدف و انتخاب‌های سریع؛ شدت طرح به‌طور خودکار از فاصلهٔ سن تعیین می‌شود |
| شبیه‌سازی | تصویر تقریبی چهره در سن هدف با لیفت ملایم نواحی، کم‌کردن سایه‌ها و یکدست‌سازی پوست، بر اساس شدت یافته‌ها. همراه با اسلایدر قبل و بعد؛ روی دستگاه ذخیره می‌شود و به اپ مراجع هم می‌رود |
| طرح درمان | سه سطح حداقلی، پیشنهادی و جامع. برای هر ناحیه: تحلیل آناتومیک، جملهٔ مناسب برای مراجع، گزینه‌های فیلر، بیواستیمولاتور، نخ، بوتاکس، دستگاه، اسکین‌بوستر، لیزر و پیلینگ با **روش انجام** (لایه، ابزار، نوع محصول)، برچسب خطر، هشدار منع مصرف و **رویکرد ترکیبی**. زمان‌بندی جلسات (بوتاکس پیش از فیلر، ساختار پیش از جزئیات، حداکثر یک ناحیهٔ پرخطر عروقی در هر جلسه) و برآورد هزینه |
| MD Codes | با یک دکمه: نواحی آناتومیک روی عکس، مسیر تقریبی عروق پرخطر و دکمهٔ اورژانس. جدول کدها تا نصب دادهٔ دارای مجوز خالی می‌ماند |
| گزارش | چک‌لیست و امضای پزشک، گزارش PDF فارسی و انگلیسی با تاریخ شمسی و میلادی، برند کلینیک و پیوست فنی اختیاری |
| مقایسه | مقایسهٔ کنار هم یا با اسلایدر بین قبل، بعد، شبیه‌سازی و جلسات قبلی |
| اپ مراجع | طرح من، عکس‌ها و شبیه‌سازی، عکس پیشرفت با همان راهنما، توصیه‌های پس از درمان، سؤال از پزشک. تبادل داده با فایل (پیام‌رسان یا AirDrop) و بدون سرور |

## اجرا

```bash
npm install
npm run setup        # کپی WASM مدیاپایپ + دانلود مدل چهره (یک بار)
npm run dev          # http://localhost:5173
npm run dev:https    # برای تست دوربین روی گوشیِ متصل به همان Wi-Fi
npm run check        # تایپ + لینت + ۸۱ تست واحد
npm run test:e2e     # Playwright (به test-assets/portrait.jpg نیاز دارد؛ در گیت ثبت نمی‌شود)
npm run build        # خروجی استاتیک PWA در dist/
```

## روند کار

**پزشک:** پنل پزشک ← آنالیز جدید (انتخاب خدمت) ← شرح حال و رضایت ← عکس‌های قبل ← آنالیز ← سن و شبیه‌سازی ← طرح درمان (و MD Codes) ← امضا و گزارش ← ارسال پرونده به اپ مراجع.

**مراجع:** اپ مراجع ← وارد کردن فایل کلینیک یا وارد کردن کد ← دیدن طرح، عکس‌ها و توصیه‌ها ← نوشتن سؤال و گرفتن عکس پیشرفت ← ارسال به کلینیک.
پزشک فایل پاسخ را در صفحهٔ بیماران وارد می‌کند؛ سؤال‌ها در پروندهٔ بیمار و عکس‌ها در بخش «بعد» قرار می‌گیرند.

## محدودیت‌های فعلی

- شبیه‌سازی تقریبی و هندسی است، نه مدل مولد هوش مصنوعی.
- شدت‌های پیشنهادی برای زیر چشم، خط خنده، ماریونت و لب از سایه و هندسهٔ تصویر می‌آیند و کالیبره نشده‌اند؛ تصمیم نهایی با پزشک است.
- نقاط نام‌دار هنوز با صفحهٔ «بازرس نقاط» تأیید انسانی نشده‌اند (M1). جهت چرخش ۴۵ درجه فقط از نظر مقدار بررسی می‌شود.
- رمزگذاری داده‌ها با PIN (M9)، آنالیز نیم‌رخ با نقطه‌گذاری دستی و تست روی گوشی واقعی باقی مانده است (جزئیات در `docs/TASKS.md`).
- متن پروتکل اورژانس، حجم‌ها و واحدها، سطح شواهد و مجوز MD Codes و مقیاس‌های Merz/Allergan باید توسط پزشک ارشد تکمیل شوند.

## پیشنهادهای توسعه

1. **سرور امن (فاز ۲):** همگام‌سازی پرونده بین پزشک و مراجع، چت هم‌زمان، نوتیفیکیشن یادآوری تمدید بوتاکس و فیلر و پیگیری مراقبت‌ها، با رمزگذاری سرتاسری.
2. **مدل سن ظاهری و آنالیز پوست** (لک، منافذ، چین ریز) روی دستگاه.
3. **شبیه‌سازی مولد** با مدل محلی یا سرور داخلی کلینیک، با رضایت جداگانه.
4. **QR کد** برای انتقال کد بیمار و نصب اپ مراجع.
5. **پرسش‌نامهٔ FACE-Q و امتیاز GAIS** برای سنجش رضایت پس از درمان، و نمودار تغییرات بین جلسات.
6. **موجودی و سری ساخت محصول** (lot number) در هر جلسه برای ایمنی و ردیابی.
7. **انتشار روی GitHub Pages** برای تست آسان دوربین روی گوشی (HTTPS رایگان).
8. **نسخهٔ بومی** با Capacitor برای فروشگاه‌های اپ.
